v9에서 바뀐 점

  1. 한 장씩 끊지 않고 이어지는 한 페이지예요. 블록마다 높이가 달라요(첫 화면만 화면 높이).
  2. 가장자리 페이드: 첫 화면 아래쪽이 다음 블록으로 흐리게 녹아들고, 뒤에 깔린 카드는 아래가 흐려져요.
  3. 포커스 강조: 업종 목록은 화면 가운데에 온 줄만 선명해지고 나머지는 옅어요. 왼쪽 제목은 고정돼 있어 맥락이 끊기지 않아요.
  4. 겹쳐 쌓이는 카드: 예상 매출 → 쓸모 트랙 → 진행 순서가 스크롤하면 위로 차곡차곡 쌓여요.
  5. 스크롤 감도: 휠을 굴리면 바로 튀지 않고 부드럽게 따라와요. 등장은 0.9초에 차례로 나타나요.
  6. 질문 화면(창업 매칭의 “아이템이 정해졌나요?” 같은 것)은 v9처럼 한 화면에 하나씩 유지할게요.
